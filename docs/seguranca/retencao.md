# Classificação e retenção (proposta)

| Registro | Retenção proposta | Observação |
|---|---|---|
| Projetos, fases, gates, decisões | Vida do projeto + 5 anos | Arquivamento lógico, sem exclusão |
| Evidências aprovadas | Conforme `retention_until`; padrão 5 anos | Nunca excluídas pela aplicação |
| Trilha de auditoria | 5 anos | IP anonimizável após 12 meses |
| Tentativas de login | 90 dias | Limpeza periódica a implementar |
| Snapshots de indicadores | 3 anos | Reprodutibilidade de insights |

Ambiente acadêmico: somente dados sintéticos; nenhum dado pessoal real deve ser inserido.
