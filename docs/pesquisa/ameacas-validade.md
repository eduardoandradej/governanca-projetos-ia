# Ameaças à validade

- **Construto**: "governança efetiva" foi operacionalizada como controles verificáveis (bloqueios, segregação, auditoria,
  indicadores); outros aspectos (cultura, engajamento) não são medidos.
- **Interna**: os testes e o artefato foram produzidos pela mesma equipe — risco de testar apenas o que foi construído.
  Mitigação: cenários T-001..T-028 definidos antes no protocolo; defeitos reais encontrados e registrados.
- **Externa**: um único template e cenário sintético de plataforma de IA; generalização para outros setores exige estudo.
- **Conclusão**: aprovação de 100% dos testes indica conformidade com a especificação, não ausência de defeitos.
- **Referencial**: fonte ISACA lida integralmente; PMBOK 8 lido nos capítulos prioritários; COBIT 2019 Framework não lido
  no original nesta etapa.
